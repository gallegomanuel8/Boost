Vídeo y audio

Las listas HLS se descargan con el motor propio de raudo; yt-dlp y ffmpeg solo se usan cuando la web lo necesita (YouTube, MP3, unir audio y vídeo).

Integración con navegadores

Firefox, Brave, Chrome y Edge envían las descargas a raudo mediante su extensión. Si un navegador no conecta, registra el puente de nuevo desde una terminal:

raudo-nmhost register
